The first time Sift opens, it asks how it runs, where it keeps its data and who its admin is. To begin, open Sift after you [install it](/get-started/install-sift/#run-the-installer).

The second and third questions each have a back button, so you can change an answer before you create the admin. To answer the first two again later, use [Settings > General > Run setup again](/settings/general#general.run_setup).

## How Sift runs

**How Sift runs** offers two choices:

- **This device**: Sift keeps your library on the computer you're installing it on. Choose it the first time you set up Sift.
- **Another device**: this window opens a Sift library that already runs on a different device. [Sift on your phone or another computer](/get-started/sift-on-your-phone/#another-computer) says how.

## Where Sift keeps its data

**Sift data** shows the folder Sift offers for its database, its settings and the files it generates, such as thumbnails. Click **Choose this folder** to keep it, or **Choose a different folder** to pick one in Windows' own folder window.

This folder never holds your photos or videos, and choosing it doesn't move them. If the folder already holds a Sift library, the button reads **Keep this library**, and Sift carries on with it.

To move these folders later, use [Settings > Folders > Sift data](/settings/library#library.storage_folders).

## Create the admin

The last question creates the admin: type a **Username**, a **Password** and the password again in **Password again**, then click the button under them. Sift has no default password, and nothing else in Sift opens until the admin exists.

The admin can see and change everything in Sift, so keep this username and password to yourself. To let another person in, give them a User of their own in [Settings > User Management > Guests](/settings/users#users.guests).

If you forget the password, [Saved Cookies and a forgotten password](https://github.com/nuvibes/sift/blob/main/SECURITY.md#saved-cookies-and-a-forgotten-password) has the way to set a new one on the computer Sift runs on.

## What opens next

Sift opens on Browse, which is empty until you give Sift a folder. Its **Add a folder** button is the next step, in [Step 3: Add your folders](/get-started/add-your-folders/#_top).
