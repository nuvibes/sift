Updates and Info is where you see which version of Sift you run, check for a new one, and read the license. To open it, go to [Settings > Updates and Info](/settings/updates).

Come here to check for a new version, or to find your device id for a swap. Sift tells you about a new version and never updates itself without asking you.

![The Updates and Info pane in Settings](../../../assets/screens/settings-updates.jpg)

## On this pane

The first rows have no heading: the version you run, the **Check for new versions automatically** switch and **Check now**. Then the pane draws these groups, in this order:

- <a id="updates.download_tools"></a>**Download tools**: the programs Sift downloads with and the version of each: ffmpeg, yt-dlp, gallery-dl and the JavaScript engine.
- <a id="updates.download_tools.yt-dlp"></a>**Check for a newer yt-dlp**: **Check** looks for a newer yt-dlp, which often fixes a download that stopped.
- <a id="updates.swaps"></a>**Swaps**: your device id, which the other Sift is shown in a swap. **Copy** copies it.
- <a id="updates.license"></a>**License and source code**: the license, the address of the source code, and **Read the notices** for the tools Sift comes with.

When a new version is out, the pane shows its release notes and how to update.
